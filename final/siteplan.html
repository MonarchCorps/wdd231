Site Name

Naija Food Hub

"Naija" is the widely recognized, affectionate informal name Nigerians use for their country. Pairing it with "Food Hub" positions the site as the central destination for discovering, exploring, and celebrating Nigerian cuisine — authentic, culturally grounded, and instantly recognizable to both the diaspora and international food enthusiasts.

Optional domain: naijafoodhub.com

Site Purpose

Naija Food Hub is a dynamic, interactive culinary guide that celebrates the rich diversity of Nigerian cuisine across all six geopolitical zones. The site provides:

  • A browsable and filterable database of 15+ authentic Nigerian dishes, each with regional origin, key ingredients, preparation notes, and cultural context.
  • A regional cuisine explorer that lets users discover food traditions from South West, South East, South South, North Central, North East, and North West Nigeria.
  • A food culture page covering Nigerian dining etiquette, food festivals, and the stories behind iconic dishes.
  • A newsletter signup form for users who want updates or to contribute a recipe.

Scenarios

These questions represent the target audience: food enthusiasts, Nigerian diaspora members, travelers, and culinary students.

"What are the most popular Nigerian dishes I should try if I'm visiting Lagos for the first time?"
"I want to cook Nigerian food at home — what ingredients are essential, and which dish is best for a beginner?"
"How does food culture differ between Yoruba, Igbo, and Hausa traditions in Nigeria?"

Three-Page Structure

Page File Description
Home index.html Hero section, featured dishes grid (loaded dynamically from JSON), region filter buttons, newsletter CTA
Recipes recipes.html Full filterable dish database (15+ items), search input, sort options, modal detail view for each dish
Culture culture.html Articles on Nigerian food culture, regional cuisine traditions, food festivals, and dining etiquette
Form Action subscribe.html Thank-you confirmation page displaying submitted newsletter data (does not count toward 3-page requirement)

JavaScript Feature Plan

Data Fetching (Fetch API + try/catch) Load dishes.json with fetch() wrapped in try...catch for robust error handling and JSON parsing.
Dynamic Content (15+ items, 4+ properties) Generate dish cards displaying: name, region, description, difficulty rating, and image from the data source.
Local Storage Save and retrieve the user's favorited dishes so preferences persist across page visits.
Modal Dialog Accessible dish-detail modal with open/close controls, keyboard trap (Tab/Esc), and ARIA attributes.
DOM Manipulation & Events Filter buttons, search input, modal triggers, favorites toggle — all via querySelector, addEventListener.
Array Methods filter() for region/search filtering, map() for card generation, reduce() for favorites count.
Template Literals All card HTML and modal content constructed using template literals for clean, dynamic string building.
ES Modules Code split into dishes.js, modal.js, favorites.js, and ui.js modules with explicit imports/exports.
